## 1.3.2

- Added support for RPCS3 extracted PlayStation 3 disc-folder games using `PS3_GAME/USRDIR/EBOOT.BIN`.
- PS3 disc-folder games now use the parent game-folder name instead of `EBOOT` as the ROM name and identifier.
- Added filtering of unrelated `.BIN` files when scanning PS3 disc-folder sources.

- Supporting new source types
- Updated to programs based file browser.
